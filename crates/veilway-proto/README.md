# veilway-proto

Wire formats of the Veilway native protocol (key derivation, chunk framing with padding, the control channel, the stream proof, pairing codes and the signed subscription format), as pure code with no IO.

This crate is part of [Veilway](https://github.com/veilway-project/veilway), a WireGuard-based VPN and proxy platform. It is alpha software: the API and the wire formats can still change between versions.
