# veilway-macos

The macOS layer of the Veilway client: utun, the routing socket, the pf kill switch, DNS through SystemConfiguration and the keychain vault. It is compile-checked and has not been run on a Mac yet.

This crate is part of [Veilway](https://github.com/veilway-project/veilway), a WireGuard-based VPN and proxy platform. It is alpha software: the API and the wire formats can still change between versions.
