# veilway-engine

The Veilway client engine without an operating system layer: the connection loop and the race of two candidates, an open session with its control channel, subscription import and the status an app is given.

This crate is part of [Veilway](https://github.com/veilway-project/veilway), a WireGuard-based VPN and proxy platform. It is alpha software: the API and the wire formats can still change between versions.
